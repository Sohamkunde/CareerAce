# CareerAce 🚀

An AI-powered interview preparation platform designed to help users practice interviews, receive AI-generated questions, and analyze their interview performance.

## ✨ Features

- 🔐 Google Authentication using Firebase
- 🤖 AI-powered interview question generation
- 🎤 Mock interview experience
- 📊 Interview performance reports
- 📚 Interview history
- 💳 Razorpay payment integration
- 👤 User profile and authentication
- 🗄️ MongoDB database
- ⚡ React-based frontend
- 🚀 Node.js + Express backend

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- React Router

- Tailwind CSS
- Firebase Authentication

### Backend
- Node.js

- MongoDB

- OpenRouter API
